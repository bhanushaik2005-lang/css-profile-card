# css-profile-card
CSS Profile Card
Author

S. Bhanu

Description

This project demonstrates how to design a profile card using HTML and CSS.

The profile card contains an image, name, job title, biography, and a contact button.

Features
Profile image
Name and job title
Personal bio
Contact button
Rounded card design
Box shadow
Button hover animation
Responsive layout
Technologies Used
HTML5
CSS3
Files
css-profile-card/
│
├── index.html
└── README.md

How to Run
Download or clone this repository.
Open the index.html file.
Open the file in a web browser.
The profile card will be displayed in the center of the page.
